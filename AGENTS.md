# Projeto Bancada / Controladoria

- Repositório principal autorizado pelo usuário: https://github.com/samuel-santos448/controladoria.
- Toda alteração futura deste projeto deve ser registrada em commit e enviada a esse repositório. Verifique a branch remota antes do envio e preserve alterações existentes; nunca use force push sem autorização específica.
- O projeto é uma aplicação estática em `dist/`. Execute localmente com `node server.cjs`.
- A publicação atual no Sites está identificada em `.openai/hosting.json`. Preserve esse ID e publique as alterações da interface também na prévia, conforme o fluxo da skill Sites.
- Valide JavaScript com `node --check` e confira no navegador os fluxos afetados. Para PDFs, verifique o conteúdo e a paginação.
- Dados do protótipo são locais ao navegador. Não envie dados reais de clientes, PDFs gerados, credenciais ou arquivos temporários ao GitHub.
